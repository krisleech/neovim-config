# Ruby Keybindings

## Tests (Neotest + neotest-rspec)

| Key          | Action                                 |
| ------------ | -------------------------------------- |
| `<leader>tr` | Run nearest spec (under cursor)        |
| `<leader>tt` | Run current file                       |
| `<leader>tT` | Run all test files in project          |
| `<leader>tl` | Re-run last                            |
| `<leader>tw` | Toggle watch mode on current file      |
| `<leader>to` | Show output for last-run test          |
| `<leader>tO` | Toggle output panel                    |
| `<leader>ts` | Toggle summary tree (run from sidebar) |
| `<leader>tS` | Stop running test                      |
| `<leader>ta` | Attach to running test                 |
| `<leader>td` | Debug nearest (dap)                    |
